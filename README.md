# Maya Chaker — Portfolio

A custom editorial portfolio for full-stack developer Maya Chaker. The site presents selected product work, technical capabilities, applied experience, and contact details in a responsive single-page experience.

## Stack

- React 19
- Vite 7
- Framer Motion
- React Icons
- CSS custom properties and responsive layout

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run type-check
npm run build
```

The production build is generated in `dist/`.

## Structure

- `src/components` — page sections and reusable interaction components
- `src/components/ui` — shared motion primitives
- `src/Data` — project, capability, and applied-work content
- `public` — résumé and favicon assets

The portfolio is intentionally static and requires no environment variables or backend service.
