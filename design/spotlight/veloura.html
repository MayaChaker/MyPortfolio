Overview

Veloura is a multi-brand beauty store. Shoppers browse makeup, skincare, fragrance and haircare, choose a shade, check out with cash on delivery and follow their order. An admin area runs the shop: orders to ship, revenue, prices and stock.

It started as a Create React App project. I moved it to Next.js and strict TypeScript in phases, then added PostgreSQL, accounts and the admin side.

Features

For shoppers

  • Filters, sorting and pages, kept in the URL
  • Shades with their own stock
  • Promo code, free-delivery threshold and a delivery pin on a map
  • Email or Google sign-in; guests can still check out

For the admin

  • Revenue, orders, low stock and best sellers for 7, 30 or 90 days
  • Orders by status, search, Placed to Shipped to Delivered
  • Prices, crossed-out "was" prices and stock per shade

How it's built

Store pages are pre-rendered from the database and rebuilt when the admin changes a product, so they stay fast. Admin and account pages render per request, behind a session check.

Checkout sends only product ids, shades and quantities. The server validates them with Zod, prices the order from the database and saves it while taking stock, in one transaction.

Decisions

Money is whole cents
Prices are stored and calculated as integers. A typed price like 19.99 is read digit by digit, never multiplied as a float.
No overselling
Every write that depends on the current value is conditional. Two shoppers buying the last item at once: one gets it, the other is told it just sold out.
Orders keep a snapshot
Names and prices are copied into the order, so editing a product never rewrites past orders.
The admin is invisible
A customer who opens an admin URL gets the store's normal 404. The role is read from the database on every request.

Testing

Jest and React Testing Library cover pricing, order status, validation, access checks, checkout and the admin forms. Integration tests run against a real Postgres, including ten concurrent requests against a rate limit of five. Playwright drives a real browser through the built site. CI runs all of it on every push.
